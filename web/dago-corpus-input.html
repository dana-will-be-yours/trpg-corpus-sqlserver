來源與批次

欄位說明筆記：stg.Utterance_Import / dbo.Utterance

基本對應：stg.Utterance_Import 是暫存匯入表；dbo.Utterance 是正式逐字稿核心表，一列代表一個 turn。turn_no_text 轉成 turn_no；speaker_code 依 speaker_type 轉成正式外鍵；utterance_text_raw / clean / verified 三層保留。

欄位意思與對應
project_code研究專案代碼，對應 dbo.Research_Project.project_code。
team_code團隊代碼，對應 dbo.Team.team_code。
session_code場次代碼，對應 dbo.TRPG_Session.session_code。
batch_code匯入批次代碼，對應 stg.Import_Batch.batch_code。
scene_code場景代碼，對應 dbo.Scene.scene_code；可空白，空白時正式表 scene_id 為 NULL。
speaker_code說話者正式代碼。GM/PL/Observer/Researcher 對應 dbo.Team_Member；PC 對應 dbo.Player_Character；NPC 對應 dbo.NPC。
speaker_label_raw逐字稿原始說話者名稱，保留原始資料來源。
start_timecode語音或影片起始時間碼，用於回溯逐字稿來源。
utterance_text_raw原始逐字稿。
utterance_text_clean清理後文本。
utterance_text_verified人工確認後文本。

speaker_type：GM＝主持人；PL＝角色外玩家；PC＝玩家角色；NPC＝非玩家角色；Observer＝觀察者；Researcher＝研究者。

function 代碼中文名稱用途
narration旁白GM 描述場景、環境、事件、NPC 狀態。
dialogue對話角色內對話或一般交談。
action行動宣告玩家宣告角色要做什麼。
rule_check規則檢定擲骰、技能檢定、規則確認、成功失敗判定。
decision決策個人或團隊做出明確選擇。
negotiation協商玩家討論方案、分配任務、協調敘事方向。
question提問詢問規則、世界觀、場景資訊、角色意圖。
clarification澄清補充、確認、修正前一段資訊。
conflict衝突立場不一致、反對、爭執或敘事衝突。
summary摘要回顧事件、整理資訊、階段性總結。
