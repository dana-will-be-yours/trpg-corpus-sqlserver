# Archived legacy frontend assets

This directory is reserved for legacy da_go corpus frontend scripts that are retained only for version traceability.

v1.4 active HTML must not load files from this directory.

Current v1.4 active files are listed in `docs/dago_corpus_input_v1_4_工作手冊.md`.

Known legacy assets that must not be used by v1.4 active HTML include older `dago-corpus-input-v*.js`, old export fixes, old DOCX handlers, and old review openers from v5-v12 generations.

Do not add new v1.4 runtime code here.
