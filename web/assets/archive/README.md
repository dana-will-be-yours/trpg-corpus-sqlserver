# Archived legacy frontend assets

This directory is reserved for legacy da_go corpus frontend scripts that are retained only for version traceability.

v13 active HTML must not load files from this directory.

Current v13 active files are listed in `docs/dago_corpus_input_v13_工作手冊.md`.

Known legacy assets that must not be used by v13 active HTML include older `dago-corpus-input-v*.js`, old export fixes, old DOCX handlers, and old review openers from v5-v12 generations.

Do not add new v13 runtime code here.
