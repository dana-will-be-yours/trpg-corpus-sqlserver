4. SSMS 22 匯入提示

  1. 先在 SQL Server Management Studio 22 建好 TRPG_Corpus_DB 並依序執行 database 腳本。
  2. 用本頁匯出 JSON 或 CSV UTF-8。
  3. JSON 可用 OPENROWSET + OPENJSON 匯入 stg.Import_Batch 與 stg.Utterance_Import。
  4. CSV 可用 SSMS 匯入精靈或 BULK INSERT 匯入暫存表。
  5. 匯入後執行既有 stg 驗證程序，再將 valid 資料寫入 dbo.Utterance。
